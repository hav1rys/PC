# Включение ПК удалённо (Wake-on-LAN)

Основной бот (`bot.js`) не может включить твой ПК, если тот выключен —
процесс бота работает **на самом ПК**, а выключенный ПК ничего не выполняет.

Единственный способ включить ПК по сети — Wake-on-LAN (WoL): magic-пакет,
который должен отправить **другое устройство**, работающее постоянно
(роутер с поддержкой WoL, Raspberry Pi, NAS, второй ПК и т.п.).

## Настройка на целевом ПК (один раз)

1. В BIOS/UEFI включить "Wake on LAN" / "Power On by PCI-E".
2. В диспетчере устройств Windows → сетевой адаптер → Свойства →
   вкладка "Управление электропитанием":
   - "Разрешить этому устройству выводить компьютер из ждущего режима" — включить
   - Вкладка "Дополнительно" → "Wake on Magic Packet" — Enabled
3. Узнать MAC-адрес адаптера: `ipconfig /all`

## Отправка magic-пакета с другого устройства

`send-wol.js` в этой папке — отдельный скрипт (не требует Node на целевом ПК).
Запускать на устройстве, которое всегда включено:

```bash
npm install wol
node send-wol.js AA:BB:CC:DD:EE:FF
```

Если хочешь управлять этим тоже через Telegram — заведи второй, отдельный
бот-токен и повесь команду /wake на этот скрипт, запущенный на
всегда включённом устройстве (Raspberry Pi, роутер с OpenWrt, дешёвый VPS
с проброшенным в локальную сеть портом и т.д.).
