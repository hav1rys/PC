# PC Control Bot

Telegram-бот для удалённого управления этим ПК: перезагрузка/выключение,
запуск приложений и игр (в т.ч. Steam), скриншоты обоих мониторов
(разово или каждые N секунд), просмотр процессов, передача файлов и т.д.

**Важно:** бот должен работать именно на том Windows-ПК, которым нужно
управлять (скриншоты, запуск игр, shutdown — всё это локальные действия).
Хостинг вроде BotHost для него не подходит.

## Установка

1. Установить [Node.js](https://nodejs.org/) (LTS), если ещё не установлен.
2. В этой папке:
   ```bash
   npm install
   ```
3. Скопировать `.env.example` → `.env` и заполнить:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
   - `ALLOWED_IDS` — твой Telegram user ID (узнать у [@userinfobot](https://t.me/userinfobot)).
     **Без этого бота сможет использовать кто угодно, кто найдёт токен.**
4. Прописать пути к играм/программам — либо руками в `apps.json`, либо
   кнопкой **➕ Добавить приложение** прямо в Telegram (see ниже).
5. Запуск:
   ```bash
   npm start
   ```

## Автозапуск при входе в Windows

Кнопка **🚀 Автозапуск** в главном меню сама создаёт/удаляет задание в
Планировщике заданий Windows (через `schtasks`, триггер "при входе в
систему", от твоего пользователя). Ничего руками настраивать не нужно —
жми кнопку один раз, и бот дальше сам стартует при каждой загрузке ПК.

## Автоскриншот при старте

Через 5 секунд после запуска процесса бота (то есть — после входа в Windows,
если включён автозапуск) бот сам присылает скриншот рабочего стола всем
из `ALLOWED_IDS`, без запроса — чтобы сразу видеть, что всё загрузилось.

## Команды

Всё управление через кнопки внизу экрана (постоянная клавиатура, не привязана
к сообщению — не пропадает при прокрутке чата). Напиши боту `/start`, дальше
только меню — запоминать команды не нужно.

## Клик по экрану (для лаунчеров/игр, где нужно тыкать мышкой)

Кнопка **🖱 Клик**: бот спросит координаты `x y` и кликнет там левой кнопкой
мыши. Порядок действий для многошаговых лаунчеров (открыл лаунчер → "Играть" →
выбор персонажа → точка спавна → "Появиться"):

1. **🖥 Скриншот** — посмотреть, что на экране. Открой присланное фото
   на весь экран (не по превью в чате) — координаты клика должны совпадать
   с реальным разрешением монитора, а не с уменьшенной картинкой в чате.
2. Посмотри на фото, в каком примерно месте (в пикселях от левого верхнего
   угла) находится нужная кнопка.
3. **🖱 Клик** → пришли координаты, например `860 640`.
4. Через секунду — новый **🖥 Скриншот**, чтобы увидеть результат и кликнуть дальше.

**🖥 Мониторы** покажет границы (Bounds) каждого экрана — если жмёшь на
второй монитор, а не на основной, координаты нужно сдвигать на его смещение
X/Y оттуда (основной монитор обычно начинается с X=0 Y=0, второй — со сдвигом).

Жёстко зашивать координаты именно под конкретный лаунчер/игру не стал —
разрешение и версии интерфейса меняются, а скриншот+клик работает всегда.
Если после пары запусков координаты у тебя всегда одни и те же — скажи,
сделаю отдельную кнопку-макрос с готовой последовательностью кликов.

## Панель настройки (в браузере)

Вместе с ботом (`npm start`) поднимается локальный веб-сервер:
**http://localhost:4100**

Там можно без правки JSON-файлов руками:
- **Приложения** — добавить/удалить/переименовать, путь, флаг "админ".
- **Макросы** — визуально собрать последовательность шагов (launch / клик по
  пикселям / клик по % экрана / пауза / скриншот), менять порядок стрелками.
- **Персонажи** и **Точки спавна** — координаты по каждому персонажу отдельно.

Изменения сохраняются сразу в те же файлы, что читает бот — просто заново
открой нужное меню в Telegram, обновлять/перезапускать бота не нужно.
Порт можно поменять переменной `ADMIN_PORT` в `.env`.

Панель и пульт закрыты ключом доступа (`ADMIN_TOKEN` в `.env` — уже сгенерирован
случайный при установке). Открывать нужно **всю ссылку целиком** — с `?key=...`
на конце, без него сервер ответит 401. Ссылку на панель со своим ключом видно
в консоли при запуске бота.

## 📲 Пульт — экран, клик и клавиатура с телефона

Кнопка **📲 Пульт** в Telegram присылает ссылку на мобильную страницу:
открываешь на телефоне (в той же Wi-Fi сети, что и ПК) — видишь актуальный
скриншот, тапаешь по нужному месту → жмёшь "Кликнуть здесь" → бот кликает
на ПК и сразу присылает новый скриншот для подтверждения. Есть и режим
"⌨️ Клавиатура" — вводишь текст (в том числе пароль) в поле, жмёшь "Ввести" —
текст печатается в то окно на ПК, которое сейчас в фокусе.

Это удобнее, чем гадать координаты по фото в чате и писать их текстом
(кнопки **🖱 Клик**/**🖥 Скриншот** остаются как запасной вариант).

**Доступ из интернета уже настроен** через Cloudflare Tunnel (`cloudflared`,
установлен на ПК): бот сам поднимает временный туннель при старте и
подставляет актуальную ссылку в сообщение кнопки "📲 Пульт" — вторая строка
("Из любой точки"). Эта ссылка вида `https://случайные-слова.trycloudflare.com`
**меняется при каждом перезапуске бота** — просто нажимай "📲 Пульт" заново,
если старая ссылка перестала работать. Первая строка (локальный адрес)
работает только в той же Wi-Fi-сети, что и ПК.

Если позже заведёшь свой домен — можно сделать постоянную ссылку через
именной туннель Cloudflare вместо `trycloudflare.com`, скажи, настроим.

Приложения, у которых есть привязанные макросы (имя вида `"ИмяПриложения: действие"`
в макросах), в Telegram-меню "🎮 Приложения" превращаются в одну кнопку-группу
со своим подменю (играть / персонаж / просто открыть) — так что "GTA5RP: играть"
и "GTA5RP: персонаж" больше не висят россыпью в общем списке.

## Про "включить ПК удалённо"

Это единственное, что сам бот дать не может — если ПК выключен, процесс
бота не работает. Решение — умная Wi-Fi розетка + отдельный бот на BotHost,
см. [bothost-poweron/README.md](bothost-poweron/README.md).
(Вариант с Wake-on-LAN через роутер тоже описан в [wake/README.md](wake/README.md),
но для твоего роутера TP-Link TL-WR841N он рискованный — требует перепрошивки.)

## Безопасность

- Никому не показывай `BOT_TOKEN` и не публикуй `.env`.
- `/run` выполняет произвольные команды в cmd — мощно, но опасно.
  Доступ есть только у ID из `ALLOWED_IDS`, так что не добавляй туда лишних людей.
- Скриншоты и статус ПК будут доступны любому из `ALLOWED_IDS` — добавляй только себя/доверенных людей.
