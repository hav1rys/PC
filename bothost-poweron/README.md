# PC Power-On Bot (для BotHost)

Отдельный маленький Telegram-бот. Его единственная задача — включать ПК
удалённо через умную Wi-Fi розетку (Tuya/Smart Life), когда сам ПК выключен
и основной бот ([../bot.js](../bot.js)) на нём не работает.

Живёт на BotHost (или любом другом всегда включённом сервере) — деплоится
так же, как KoopTeh.

## Как это работает

1. ПК подключён к сети через умную розетку.
2. В BIOS материнской платы включена настройка вида "Restore on AC Power Loss" /
   "AC Back Function" / "Power On after Power Loss" = **Power On** (найти в разделе
   Power/APM Configuration; называется по-разному у разных производителей плат).
3. Этот бот по кнопке дёргает Tuya Cloud API → розетка подаёт питание → ПК
   загружается сам, как будто его включили кнопкой на корпусе.

## Настройка Tuya Cloud API

Это самая муторная часть, делается один раз.

1. Установи на телефон приложение **Smart Life** (не обязательно "Умный дом с
   Алисой" — именно Smart Life, это "родное" приложение Tuya) и добавь туда
   розетку (сканированием при первом включении розетки).
2. Зарегистрируйся на https://iot.tuya.com (можно через тот же аккаунт).
3. В консоли: **Cloud → Development → Create Cloud Project**.
   - Data Center: выбери ближайший к тебе (для России обычно подходит
     "Central Europe Data Center" — от этого зависит `TUYA_BASE_URL`,
     см. таблицу ниже).
   - После создания проекта на вкладке **Overview** будут `Access ID/Client ID`
     и `Access Secret/Client Secret` — это `TUYA_ACCESS_KEY` / `TUYA_SECRET_KEY`.
4. В проекте: вкладка **Devices → Link Tuya App Account** → появится QR-код →
   отсканируй его в приложении Smart Life (профиль → значок QR в углу) —
   это привяжет твои реальные устройства к облачному проекту.
5. После привязки в списке устройств появится розетка — скопируй её
   **Device ID** → это `TUYA_DEVICE_ID`.
6. Если проект новый, может понадобиться на вкладке **Service API** подключить
   (Subscribe) пакет **IoT Core** — обычно доступен бесплатно (trial),
   без него запросы будут возвращать ошибку доступа.

Таблица `TUYA_BASE_URL` по дата-центрам (смотри, какой выбрал при создании проекта):

| Data Center             | TUYA_BASE_URL                   |
|--------------------------|----------------------------------|
| China                     | https://openapi.tuyacn.com      |
| Western America           | https://openapi.tuyaus.com      |
| Eastern America            | https://openapi-ueaz.tuyaus.com |
| Central Europe            | https://openapi.tuyaeu.com      |
| Western Europe             | https://openapi-weaz.tuyaeu.com |
| India                      | https://openapi.tuyain.com      |

## Установка и запуск

```bash
npm install
```

Скопируй `.env.example` → `.env`, заполни `BOT_TOKEN` (новый, отдельный от
основного ПК-бота — от того же @BotFather, но **другой** бот),
`ALLOWED_IDS` и Tuya-переменные из шагов выше.

```bash
npm start
```

## Команды бота

Всё через `/start` → кнопки:
- 🟢 Включить ПК (с подтверждением)
- 📊 Статус розетки

Специально нет кнопки "выключить" — резко обрубать питание работающего ПК
через розетку опасно (как выдернуть шнур из розетки). Для выключения/
перезагрузки используй основной бот на самом ПК (`shutdown`/`restart` —
штатные команды ОС, корректно завершают систему).
